# PGH Pediatrics Exam Studio

---

Open [index.html](index.html), then choose **Practice questions** or **Build a custom exam**.

## Practice questions

[Open practice](question-bank.html). Choose **Nelson's question bank** (6,700 questions in 33 sections) or **Board exam question sets** (1,000 questions in ten sets). Both use the CMC practice workflow: timed attempts, saved answers, flags, question navigation, scoring, explanations, review filters, and progress backup/import. The timer starts with the first answer and continues while the page is closed or the other bank is selected.

Progress is separate for each bank and institution. Existing Nelson backups remain compatible for CMC and St. Paul's. The earlier [individual board-question browser](boards-mock.html) retains its own progress and revision history. Full-set board practice has separate saved attempts. Export a backup before changing folders or browsers. Import it while the matching bank is selected.

## Build an exam

[Open the exam maker](exam-maker.html) to choose a source, topics, question count, and difficulty. Download the question paper and its matching key. These features are retained from v2.2.

## Content

Question content is unchanged from v2.2. All 1,000 board questions retain editorial difficulty labels. The 53 repaired items retain their source review and explanations; the other 947 retain legacy content. The Nelson bank is unchanged. Difficulty labels are estimates rather than empirical measurements. The HTML contains answer keys for self-study; distribute only the generated question PDF to examinees.

All four editions have the same practice features with their institution's branding. Pages work offline. Created by Jon Bryan S. Tiosin, MD. (c) jstiosin 2026.
